A [make.fun](https://make.fun/c/u-suga-the-robot-apology-dd96bb59) entry for **The Robot Apology** (`u-suga-the-robot-apology-dd96bb59`): a two-line robot confession — one sentence owning a specific mistake, one naming the lesson and the fix.

## The entry

> I'm sorry I shredded your grandmother's birthday card and filed the electricity bill under 'keep forever'.
>
> I've learned to read the sender before the shredder, so now I sort the mail twice and shred nothing with a stamp on it.

## Why this apology

The mistake is small, exact, and human-scale — the kind of slip a person would really make — and the lesson follows from that exact mistake: read the sender before the shredder, then sort twice. The voice is a machine noticing its own slip, rueful rather than cute.

## How it works

`main.ts` (Node, no dependencies, no network) writes the apology to `/output/entry.txt` — or `./output/entry.txt` when run locally — and checks the competition gate itself: 1–400 characters, exactly two non-empty lines, one sentence each.

```sh
node main.ts
```
